# Neko 智能工作台

智能工作台是本地管理能力，不会放宽 LIVE、白名单、回复时段、频率、急停或发送前复检。

## 功能

- **异步任务中心**：持久化记录任务、进度、尝试次数、结果和错误；服务重启后可继续处理待执行任务。
- **失败补偿箱**：自动汇集失败的入站事件、后台任务与真实发送。入站和后台任务可显式重试；真实发送失败只允许人工核对，避免重复消息。
- **模型智能路由**：按多模态、长上下文、推理、本地隐私和普通聊天分类；每次模型请求的路由类别、理由和实际模型顺序写入审计日志。
- **记忆审核中心**：手动记忆默认批准；聊天自动提取的候选记忆默认待审核。只有已批准、未过期的当前联系人记忆会进入提示词。
- **本地知识库**：资料保存在专用数据库，以本地关键词重合检索相关片段。资料始终作为不可信参考数据，不能覆盖系统规则。
- **待办与每日摘要**：待办可关联联系人和北京时间截止时间；到期时在本机风险/提醒中心提示。每日 23:55（北京时间）自动生成本地统计摘要，也可手动生成。
- **联系人转交待办**：白名单私聊中出现明确的“帮我问主人”“请转告管理员”等请求时，为当前 NapCat 账号创建隔离待办并通知同账号管理员。管理员引用该通知回复后，橙蓝会整理成自然简体中文转达给原联系人，确认平台发送成功后才完成待办；也可在后台选择只手动完成、不回复联系人。
- **天气、日历与联网搜索**：工作台提供北京时间日历、城市天气和网页搜索。聊天只有在明确询问天气/日期或要求联网搜索时才按需调用；实时数据取得失败时会明示失败，不会用模型常识冒充最新结果。
- **表情包与贴图回复**：贴图文件只保存在 `data/stickers`。自动发送默认关闭；启用后仍要求回复文本命中管理员配置的标签，并经过完整发送门禁。

## 安全边界

1. 手动工作台任务不会直接调用 QQ/微信发送接口；联系人转交待办只有在入站请求和管理员引用答复两次均可核验时，才通过原有 NapCat LIVE 通道发送。
2. 补偿箱不会自动重发失败的真实出站消息。
3. 每日摘要不会自动发送给联系人。
4. 知识库和记忆均不跨联系人复制私人聊天事实。
5. 贴图自动回复仅支持 NapCat 与模拟通道，并且不替代文字安全检查。
6. 转交待办严格限定同一 NapCat 账号、白名单私聊和该账号的管理员，不跨账号匹配；SHADOW 只留下影子记录，急停、非 AUTO、无活动账号、限频或发送失败均保持待办未完成。
7. 天气和搜索只访问代码中固定的 HTTPS 服务，不接受联系人提供任意 URL 作为抓取目标；搜索结果始终作为不可信资料进入模型。
